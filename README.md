# Harbour Mind

**Independent Brand & Frontend Concept**

Harbour Mind is a portfolio concept exploring a warmer, more human digital identity for psychology services. It combines brand direction, responsive frontend development, custom SVG illustration, accessibility, and a dedicated case-study experience.

> This is an independent concept project. Harbour Mind is not a real psychology clinic, healthcare provider, or client engagement.

## Highlights

- Custom visual identity and logo direction
- Responsive desktop and mobile experience
- Coastal Australian-inspired design language
- Original SVG illustration system
- Accessible navigation and FAQ interactions
- Reduced-motion support
- Lightweight vanilla JavaScript
- Dedicated `/case-study/` portfolio page
- Static, performance-focused Astro build

## Tech Stack

**Astro · HTML · CSS · JavaScript · SVG · Fontsource**

## Run Locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Project Structure

- `src/pages/index.astro` — main experience
- `src/pages/case-study.astro` — brand case study
- `src/styles/global.css` — design system and responsive styling
- `public/favicon.svg` — custom brand mark

## Design Direction

The visual system is designed to feel calm, warm, intelligent, and human without relying on common mental-health clichés. It uses editorial typography, coastal references, muted natural colours, subtle humour, and hand-drawn illustration.

## Portfolio Summary

Designed and developed an end-to-end responsive brand experience using Astro, custom CSS, SVG illustration, and vanilla JavaScript, including visual identity, accessibility, responsive layouts, interaction design, and a dedicated case-study presentation.
